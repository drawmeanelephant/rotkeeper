# Command reference

For task-based instructions, start with [Help](../help/index.html).
This index is generated by `bash rotkeeper.sh dip` from the dispatcher's
static help and script mappings. Each reference page comes from the script's
header, help block, side-effect annotations, reviewed sidecar, and changelog.
Do not maintain a second command list here.

`smoke` is an alias for `test`, not a separate command. Run
`bash rotkeeper.sh <command> --help` for usage. The
[dispatcher reference](rotkeeper.html) documents top-level help, version,
command routing, and aliases. Internal helpers and the
[setup script](scripts/setup.html) are not dispatcher commands.

```bash

bash rotkeeper.sh autopsy --all
bash rotkeeper.sh dip
bash rotkeeper.sh render
bash rotkeeper.sh links
```
