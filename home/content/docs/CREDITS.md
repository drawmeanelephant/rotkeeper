# Credits

acknowledges project contributors and Oliver. It credits the project
maintainer's work on navigation glue and identifies
[Oliver](https://github.com/drawmeanelephant/oliver) as the renderer that
succeeded Apex.

Credits describe attribution, not an operational contract. See the
[Oliver contract](oliver-contract.html) for installation and rendering
requirements.
