# bones/config/version

The single canonical version source for Rotkeeper. It is a plain text file
containing one semver-style version line, e.g. `0.5.1`.

## Who reads it

- `rotkeeper.sh` — dispatcher `--version` and help header, and the default release version.
- `rc-utils.sh` (`rk_load_version`) — every dispatcher script inherits `VERSION` from it.
- `rc-bump.sh` — reads it as the current version and is the only writer.
- `rc-status.sh` — reports it as `canonical_version` and flags the source.
- `rc-test.sh` — derives the release version under test from it.
- `rc-release.sh` — names the canonical distribution archive with it (when no explicit version is given).

## How to change it

Do not edit this file by hand. Use the bump ritual:

```bash
./rotkeeper.sh bump --patch -m "message"
./rotkeeper.sh bump --minor -m "message"
./rotkeeper.sh bump --major -m "message"
./rotkeeper.sh bump --to 0.6.0 -m "message"
```

`rc-bump.sh` validates the target as semver-style (`X.Y.Z`), writes the new
version here, and appends the matching `CHANGELOG.md` entry.

## Overrides

`ROTKEEPER_VERSION` overrides the runtime value read from this file, but never
overrides a bump — bump always operates on the canonical file.
