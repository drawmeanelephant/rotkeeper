## Terminal palettes

Brutal exposes three terminal presets as pure token overrides — set
`palette: mac|unix|pwsh` in the frontmatter of any page using
`theme-brutal.html`. No JavaScript, no CDN, no new templates; the stack and
the mechanics stay identical, only the colors move.
