### Design

The file contains the single path `bones/book-reports`. The repository
operating manual identifies that directory as generated retrieval material,
not ordinary source.

### Limits

No Rotkeeper runtime script parses `.agentignore` as an access-control list. It does not control DIP
discovery, binder writes, filesystem permissions, or Git tracking.

### Cautions

Do not treat the file as a security boundary. Check the actual source when
a generated book conflicts with it.
