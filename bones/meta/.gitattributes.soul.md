### Design

The file contains the single rule `* text=auto eol=lf`. It forces every
text file to check out with LF line endings on every platform, including
git clients that default to `autocrlf` (Git for Windows).

### Limits

The rule affects checkout line endings only. It does not change blob
content for files already committed with LF endings, and it does not mark
binary files, which Git detects separately.

### Cautions

Do not weaken it to a narrower pathspec. Renders emit LF, golden fixtures
are compared byte-for-byte with `cmp`, and embedded CR leaks into
generated HTML, so a mixed-ending checkout fails the golden regression
and injects stray carriage returns into output pages.
