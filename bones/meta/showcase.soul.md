### Architectural Intent
The `showcase/` directory contains high-stress markdown files generated by `rc-showcase.sh`. It ensures that updates to standard brutalist themes (`home/assets/css/`) and HTML structures (`bones/templates/`) degrade gracefully without visual breakage.

### Directory / File Schema Expectations
Files are dynamically generated. Expect heavy use of complex markdown tables, blockquotes, and nested lists designed to stretch CSS boundaries. Manual content additions here are subject to overwrite during a showcase ritual run.
