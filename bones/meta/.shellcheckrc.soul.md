### Architectural Intent
The `.shellcheckrc` file enforces a deterministic, strict shell style across the entire Rotkeeper project. By explicitly defining ignored rules and required globals, it ensures that all bash scripts remain POSIX-compliant and free of common footguns. This is a core component of Rotkeeper's brutalist architecture, guaranteeing that the terminal-based toolkit executes reliably across different POSIX environments.

### Directory / File Schema Expectations
Located at the root of the repository (`.shellcheckrc`), it uses standard Shellcheck configuration syntax. It is expected to be read automatically by IDE extensions, local manual invocations of `shellcheck`, and during CI runs.

### Ritual Warnings
