### Design

The configuration disables `SC1090`, `SC1091`, `SC2034`, `SC2317`, `SC2181`,
`SC2076`, `SC2053`, `SC2155`, and `SC2269`. Comments explain each exemption.
CI runs ShellCheck on the dispatcher, Rotatui, and the `rc-*.sh` scripts.

### Limits

ShellCheck is static analysis, not proof of correct runtime behavior.
Rotkeeper uses Bash-specific syntax; this configuration does not establish
POSIX-shell compatibility.

### Cautions

Keep the existing targeted exemptions. Do not add blanket quoting,
strict-mode, or subshell exemptions to hide failures. Run syntax checks and
the dispatcher test harness as separate validation steps.
