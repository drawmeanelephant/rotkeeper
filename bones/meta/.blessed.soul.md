# 🛡️ The Blessed Register

The `.blessed` file lives at the root of the repository as an immutable ledger. It acts as a safety boundary for portably deployed sandboxes.

## ⚖️ Operational Mandate
Any target path or folder registry explicitly declared inside this file is granted automatic immunity by `rc-dip.sh`.
- **The Whitelist:** Prevent accidental "whisking" or deletion of manual scripts that have not yet been mirrored into the core `bones/` lifecycle.
- **Rule of Engagement:** If an agent or pilot attempts an automated sweep, this register takes absolute precedence over disk-find outputs.
