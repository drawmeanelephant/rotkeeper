### Architectural Intent
The `docs/` directory is the central hub for Rotkeeper documentation. It aggregates human-written guides and automatically generated reports. It remains isolated from production source but represents the highest authority on system operation and design constraints.

### Directory / File Schema Expectations
This directory primarily stores standard `.md` markdown files. Subdirectories mirror internal structures (e.g., `docs/bones/scripts/`) generated by `rc-autopsy.sh` and `rc-dip.sh` processes. User documentation and manuals belong directly within this root or distinct subdirectories.
