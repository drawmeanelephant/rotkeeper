### Purpose

This directory holds authored task guides and reference pages under the
active content root. DIP generates owned command references and its matrix.
Documentation is not a substitute for checking the source.

### Contents and conventions

Reference paths mirror core paths, such as `bones/scripts/rc-assets.md`.
Task guides have their own authorship and are not rebuilt as command
references. Glue lists immediate child directories and content pages in
`index.md`; directory sidecar metadata is used when creating that index.
